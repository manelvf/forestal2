
## Forestal ##

This is a timber tracking application developed for a small private company.


### Features ###

* Complains PEFC certification 
* Timber delivery tracking, from origin land to destination

### Implementation ###

It's a web application based on Python 2.6 or 2.7 and Django 1.3.x. It can work with different versions but surely needs patching. 


### Requirements ###

Server side:

* Django 1.3
* django-reversion
* django-admin-tools
* south

Client side:

* jqGrid 3.x (included)
